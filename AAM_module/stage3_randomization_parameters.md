# Stage 3 — Candidate randomization parameters

Status: **complete**.

Selected candidates:

- Hydraulic: flow gain, compliance/bulk modulus, seal/leakage and pressure.
- Mechanical: cutter mass scale and cutter COM-z offset.

Excluded from the primary vector: emergent delay, joint damping, inertia,
dead-zone parameters and viscous friction. They either lacked a clean factor
interface, a safe symmetric range or sufficient evidence.
