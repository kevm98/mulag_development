## 8. Cylinder and Valve Ordering

Per the column manifest in `collect_open_loop.txt`:
- **Columns 6-9** (`u1`..`u4`): Cylinder 1-4 valve commands
- **Column 36** (`u5`): Joint-5 command
- **Columns 10-13** (`x1`..`x4`): Cylinder 1-4 extensions
- **Columns 14-17** (`xd1`..`xd4`): Cylinder 1-4 extension velocities
- **Columns 18-21** (`dP1`..`dP4`): Cylinder 1-4 pressure differences
- **Columns 22-25** (`F1`..`F4`): Cylinder 1-4 forces

**Cylinder mapping from source code:**
- For cylinders 1-2: `A_piston = 0.2513 m²`, `stroke = 1.85 m`
- For cylinders 3-4: `A_piston = 0.1256 m²`, `stroke = 2.25 m`

Cylinders 1-4 correspond to the four active cylinders. Joint 5 is a passive fifth joint with independent valve command `u5`. Per the AAM scope, only cylinders 1-4 are used.

## 9. Sign Conventions

- Valve commands: [-1, 1] range, dimensionless
- SIGN_1..SIGN_4 all set to +1.0 in valve_excitation (no sign inversion needed)
- Extension measured from closed position (x_min=[0,0,0,0], x_max=[1.85,1.85,2.25,2.25])
- dP = PA - PB (chamber A minus chamber B)
- Force is logged directly from Simscape cylinder force sensor

## 10. Valve/State Temporal Alignment

The valve command `u_t` is applied at time t, and the resulting state `(x_t, xdot_t, dP_t, F_t)` is measured at the same time t. In Simulink, the MATLAB Function block outputs `u_t` at discrete intervals, and the logged signals capture the state at the same `OutputTimes` grid.

Both open-loop and closed-loop use `SpecifiedOutputTimes` with uniform grids, so `u_t` and `(x_t, ...)` are temporally aligned by construction.
